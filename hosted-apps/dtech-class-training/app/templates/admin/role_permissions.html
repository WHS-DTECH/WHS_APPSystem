Page Descriptions

  • Dashboard: Main hub page showing enrolled courses, recent assignments, and progress summaries.
  • Courses: Browse and enrol in available programming courses.
  • Progress: View detailed learning progress and completion tracking across all modules.
  • Assignments: Submit programming assignments and view feedback from teachers.
  • Admin: Administrative functions — user management, course creation, grading, and system settings.

Important Notes

  • Teacher role should always have Admin access to prevent lockout.
  • Student role cannot be granted Admin access for security reasons.
  • Changes take effect immediately for all users on their next page load.
  • Permissions are stored server-side in role_permissions.json.

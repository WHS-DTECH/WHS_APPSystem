    Curriculum Progression Results

    Statements are quoted from the Technology Years 0-10 teaching sequence (September 2026), following its Knowledge and Practices layout for the student's year level. Tags show the DTECH pathways each statement supports (Admin > Curriculum Mapping): DS Digital Systems, D&I Data and Information, DC Digital Citizenship, P&A Programming and Algorithms, S&C Systems and Control. Primary Supporting Context dependent When a student completes a tracked activity, its approved statements are set to Some Evidence automatically; only the teacher can set Full Evidence. Discipline defaults to DTECH; change it if the student met the statement in Textiles, Food, Wood or DVC. Each Knowledge or Practices table is a Statement Set with a Set Progress indicator, set automatically: 1 Emerging when any statement has evidence, 2 Developing when at least 3 have Some or Full Evidence, and 3 Consolidating when every statement has Full Evidence. Once a set is Consolidating the teacher may raise it to 4 Proficient or 5 Exceeding; if evidence later drops, it returns to the automatic level.
